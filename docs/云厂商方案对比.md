# 云厂商方案对比与到期衔接策略（AWS vs Azure vs GCP）

本仓库默认的 Hysteria 2 服务端配置与双节点客户端模板不绑定特定云厂商：只要是一台带公网 IPv4、能开放自定义 UDP 端口的 Ubuntu 主机，都可以复用[服务端模板](../examples/hysteria-server.yaml)和[客户端模板](../examples/flclash.yaml)。

本文对比 **AWS Lightsail**、**Microsoft Azure** 和 **Google Cloud（GCP）** 三种搭建方案的真实成本、免费额度规则与隐形计费陷阱，方便选型以及在免费期到期后平滑衔接。

## 一、三方案核心对比

| 维度 | AWS Lightsail（主力推荐） | Microsoft Azure | Google Cloud（GCP） |
| --- | --- | --- | --- |
| **新户体验金** | 新户 $100 抵用金（完成任务最高 $200），有效期一般最长 6 个月；部分 Lightsail 套餐另有 3 个月试用 | 新户 **$200 抵用金**，但**仅限前 30 天**，到期清零 | 新户 **$300 体验金**，有效期 **90 天** |
| **长期免费机型** | 免费计划到期后按套餐付费，无永久免费亚洲节点 | 升级 Pay-As-You-Go 后享 **12 个月免费**：`B1s` / `B2ats v2` 每月 750 小时（仅够 1 台 24/7） | Always Free `e2-micro` 仅限美国 3 个区（`us-west1`/`us-central1`/`us-east1`），**不含亚洲区** |
| **月度固定成本（付费期）** | 极低且透明：IPv4 双栈低配套餐约 **$5～$7 / 台 / 月**（含静态 IPv4） | 免费期内若用静态 IPv4 约 **$3.65 / 月**；付费期亚洲区小型 VM + 磁盘 + IP 约 **$12～$18 / 台 / 月** | 亚洲区（东京/新加坡/台湾）`e2-micro` 约 **$6.5～$7.5 / 月**，另加磁盘与 IP 约 **$9～$12 / 台 / 月** |
| **流量计费（核心差异）** | **打包计费**：$5～$7 套餐自带 **1 TB～2 TB / 月** 出站流量，极难超额 | **按量计费**：Free Tier 12 个月通常仅含 **15 GB / 月**（Pay-As-You-Go 常规含 100 GB / 月）；亚太区（Zone 2）超额 **$0.12 / GB** | **极易踩坑**：默认 **Premium Tier** 发往中国大陆**无免费额度**，从第 1 字节起 **$0.23 / GB**；手动切 **Standard Tier** 后有 200 GB 免费额度，超额约 **$0.085 / GB** |
| **账单失控风险** | 低（套餐封顶直观，支持 Free Plan 保护） | 中（$200 有 30 天消费上限保护；升级 Pay-As-You-Go 后需盯紧流量和静态 IP） | 高（忘记切 Standard Tier 时，刷视频/下载很容易产生高额流量费） |
| **适合场景** | **长期自用、双节点主力、省心怕踩坑** | **30 天免费过渡**，或 **12 个月轻流量单节点** | **90 天体验金过渡**，或有现成通用 GCP 抵用金且懂网络层级配置 |

> [!NOTE]
> 以上价格与免费规则为常见公开标准，各云厂商会不定期调整区域定价、免费额度与税费。开机器前务必以你本人账户的账单页与创建页显示为准。

## 二、关于“Gemini 会员送 GCP 额度”的特别核实

经常有人提到订阅 Google AI（Gemini）会员会赠送 Google Cloud 额度，能否直接用来白嫖 GCP 节点。实际核实需要注意三点：

1. **额度来源与金额**：订阅 **Google AI Pro**（$19.99/月）可通过 Google Developer Program 领取 **$10 / 月** 额度；**Google AI Ultra 5x** 送 **$40 / 月**，**Ultra 20x** 送 **$100 / 月**（在 Google AI Studio 领取并绑定 Cloud Billing）。
2. **核心限制——多为 GenAI 专用**：这类通过 Google Developer Program 发放的月度额度，主要面向 **Gemini API / Vertex AI 等 GenAI 服务**，**不能默认直接抵扣 Compute Engine 虚拟机和公网出站流量**。是否支持通用基础设施，必须以你账户 **Billing → Credits** 页面列出的适用产品范围为准。
3. **预付账户门槛**：部分结算账户需要先保持大于 $0 的余额（如最低充值 $5）才能触发抵用金抵扣。如果流量未命中抵用范围，费用会直接从付款方式扣除。

**结论**：如果你本来就有 Gemini 会员，可以先在 GCP Billing 里核实该抵用金是否覆盖 Compute Engine；**不要在未核实前直接拿它当免费 VPN 机子用**，否则容易出现计算费 + `$0.23/GB` 流量费直接扣卡的情况。

## 三、AWS 到期后怎么继续往下用（衔接策略）

按「省心程度」与「现金预算」分为三条路线：

### 路线 A：继续留在 AWS Lightsail（最推荐、最省心）

适合希望**稳定长期用、不想频繁折腾迁机和盯流量账单**的用户。

- **检查现有账户**：先在 AWS **Billing and Cost Management → Bills / Credits / Free Tier** 确认当前抵用金余额与免费计划到期日。
- **按需降配控成本**：若之前开的是 $7/月 套餐，到期前可评估是否换到 Lightsail 最低档 IPv4 双栈套餐（如 $5/月含 2 TB 流量，或仅保留 1 台常用主力区域节点）。
- **优势**：1 台每月约 $5，2 台约 $10，自带 TB 级流量和免费绑定静态 IPv4，几乎没有流量刺客风险，且现有客户端无需改架构。

### 路线 B：多云免费期接力（追求最低现金支出）

适合愿意花半小时迁机、想把大厂新户额度依次用完的用户。建议在上一家到期前 **5～7 天** 开始搭建下一家，验证通过后再删旧机，避免断网：

1. **第 1 阶段（AWS）**：用完 AWS 新户 $100～$200 抵用金与 Lightsail 试用期。
2. **第 2 阶段（Azure）**：开 Azure 新户，先用 **$200 / 30 天** 跑双节点；第 30 天前按需升级为 Pay-As-You-Go，缩容为 **1 台免费 `B1s` / `B2ats v2`**（继续白嫖 11 个月，注意控制月出站流量、了解静态 IP 费用）。详见 [Azure 实操指南](Azure实操指南.md)。
3. **第 3 阶段（GCP）**：开 GCP 新户，用 **$300 / 90 天** 跑东京/新加坡双节点（务必将网络层级设为 **Standard Tier**，并设好预算告警）。详见 [GCP 实操指南](GCP实操指南.md)。

**平滑切换方法**：三家云的服务器都运行同一套 Hysteria 2 服务端。迁机时只需把新机器的公网 IP、端口、新生成的口令与证书 SHA-256 指纹更新到私有 `flclash.yaml` 或 Shadowrocket 链接中，备用设备测通后再停旧机、删旧资源。

### 路线 C：轻量备用（GCP 美国永久免费）

如果只是偶尔查资料、流量极小，可以在 GCP 美国免费区（如 `us-west1` 俄勒冈）开一台 `e2-micro`，并将网络层级设为 **Standard Tier**。但跨太平洋延迟较高、晚高峰易波动，不建议替代东京/新加坡主力线，仅作紧急备用。
